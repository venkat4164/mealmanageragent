## ✨ Overview

MealManagerAgent is an agentic AI application built using Google ADK + Gemini that automates everyday meal planning.

---

## 🚀 Features

- Meal Planning
- Grocery Generation
- Task Scheduling
- MCP Tool Integration
- Firestore Storage
- API-first design

---

## 🧠 Architecture

User → API → Root Agent → Sub Agents → Tools → Firestore → Response

---

## ⚙️ Setup

pip install -r requirements.txt  
python agent.py  

---

## 🌐 API

POST /api/v1/mealmanager/chat
